# Mind Palace 核验链算法与实验汇报

## 一、骨架论文:Enter the Mind Palace: Reasoning and Planning for Long-term Active Embodied Question Answering(CoRL 2025)

### 1. 解决的问题

假设机器人在办公室巡检了几天，今天有人问它：「昨天放在前台的包裹，现在还在那里吗？」

要回答这道题，机器人要先查昨天的记录，确定包裹和它当时的位置，再去前台看看今天的状态。还有一些题只需查历史，例如「昨天雨伞放在哪？」有些题只需观察现场，例如「现在桌上有几个杯子？」因此，机器人需要根据问题判断**要用哪个时间段的信息、要不要去现场，以及什么时候可以回答**。

论文把这类任务称为**长期主动具身问答**（LA-EQA）。「长期」指机器人可以使用多次巡检留下的记忆。「主动」指它可以为了回答问题，移动到新的位置并获取当前图像。

### 2. 技术路线

**第一步，把长期记忆整理成「时间片 → 区域 → 视点」。**

**第二步，根据问题查历史或去现场。** 系统从题目里识别要找的对象，先选相关时间片，再选区域和具体视点。选中历史视点时，直接调取以前拍的图。选中当前视点时，机器人需要移动过去并拍摄。区域搜索会考虑目标可能在哪，以及走过去要花多少路程。新取到的图像和观察结果会进入本题的工作记忆，供后续决策使用。

**第三步，判断是否停止核验，然后回答问题。** 停止规则：VLM根据题目和工作记忆判断已有信息是否足够

## 二、算法机制

### 1. 研究问题

Mind Palace 为机器人提供了两种获取信息的途径：查阅过去的图像，或者移动到现场观察。我们在此基础上研究一个核验决策问题：当历史记忆可能过时、现场画面也可能看不清时，机器人如何在有限预算内，决定**已有证据是否足以回答整道题，以及下一次核验该花在哪里**？

例如，用户问「昨天在楼梯上的玩具鸭挪走了吗？」历史图可以确认昨天是哪只鸭子、它在哪一级台阶。当前图则要拍清同一处，才能判断它是否还在那里。假如当前画面里没看到鸭子，但原来的台阶被栏杆挡住了，机器人还需要换角度观察。

### 2. 停止规则｜设计点一：把整题的证据要求拆成可检查的条件

| 题目类型 | 答题所需的证据 |
| --- | --- |
| 历史，例如「昨天鸭子在哪？」 | 图像属于题目指定的时间段，能辨认目标并确定它当时的位置。 |
| 当前，例如「红背包现在在哪？」 | 当前图像能够支持目标身份和当前位置。历史图可以帮助辨认背包。 |
| 过去and当前，例如「鸭子还在昨天那一级台阶上吗？」 | 历史图能确认目标和原位置，当前图能拍清同一处，且支持判断目标是否仍在那里。 |

每次实际核验后，系统把图像来源、时间、视点、覆盖范围以及已确认的事实记入**证据账本**。每轮先检查整题所需的证据是否齐全。齐全就停止并回答。仍缺证据且还有预算和合法动作，就继续查。预算用完或没有可执行动作时，只回答证据支持的部分，剩余部分保留未知。最后一次如果补齐了证据，也按证据充分结束。

**这个设计让系统能明确指出还差哪项证据。** 例如，拍清了旧台阶且没有发现鸭子，可以支持「原位置未见」。如果用户还问「它现在在哪」，就需要另有证据确认当前位置。

### 3. 核验链｜设计点二：用整题证据能否补齐来比较核验动作

证据不足时，系统有两类主要动作：

- **M，查历史图。** 可以获得旧位置、地标或能用于辨认目标的外观特征，不产生现场移动。
- **C，去现场观察。** 可以直接确认目标，也可能只拍到疑似目标或部分外观，需要查历史比对或换角度补拍。

#### 3.1 先预测动作可能取得什么证据

对每个候选动作，系统先预测它可能返回的结果，以及各结果出现的概率。记为p(o|s,a)，表示在当前状态s下执行动作a，得到结果o的概率。当前状态包含已取得的证据、机器人位置和剩余预算。

两类概率暂时根据日志的统计概率取 **历史 0.35、现场 0.20**。这两个数是「该类动作可能带来有用观察」的粗略估计。

#### 3.2 核验分怎么算

根据不同程度的证据设置了**有效分**，用来区分「拿到了一条线索」和「已经足够回答」。

| 题型 | 取得的证据 | 原型有效分 |
| --- | --- | ---: |
| 当前定位题 | 只取得历史位置或身份线索 | 0.15 |
| 当前定位题 | 当前证据支持目标身份和当前位置 | 1.00 |
| 过去—当前变化题 | 取得其中一侧所需的状态证据 | 每侧 0.30 |
| 过去—当前变化题 | 两侧形成可对齐、足以支持结论的证据对 | 1.00 |

#### 3.3 后续方案怎么计算整题证据充分的概率

暂时采取决策树，对前瞻的第一步的每种可能结果，分别推演后续最佳动作，再将各分支的成功概率加权求和。

确认正确要求答案评分至少 4/5，且有实际证据支持。

发现：
```
1.LLM开启思考模式的情况下，前瞻步数H从1到2有明显增益，从2以后增益不明显。

```
