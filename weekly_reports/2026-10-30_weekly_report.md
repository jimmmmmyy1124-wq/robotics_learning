## 一、我的原研究方案

- **研究问题：** 记忆可能存在5类不可靠的情况。机器人先判断可能是哪一类，再决定**是否核验、核验什么、先做哪一步、去哪里观察**。5项检查是可以同时出现的问题线索，不是5选一分类。
- **核心方法：** 以 **ReMEmbR** 的时空记忆与检索为基础，借用已有方法检查记忆；比较**复核旧图、修正坐标、重查实例关联、到现场观察**等操作的预期收益和成本。把机器人当前位置、后续路线、剩余预算一起纳入决策，先用**2～3 步有限前瞻**选择动作；执行后更新证据和位置，再次决策。
- **拟创新空间：** 希望设计一套**不同核验方式与导航路径的联合决策算法**：不只看某次核验是否增加可信度，而是看它能否改变目标判断、后续观察地点和任务成功率，并控制实际执行及规划计算成本。

## 二、与六篇相近论文的对比

### [When Is a Memory Safe Enough to Act On? Action-Conditioned Verification for Long-Lived Agents](https://arxiv.org/abs/2610.31446)（2026 年 10 月 22 日；AMV-Guard）

- **研究问题：** 记忆可能不可靠时，智能体应该**核验哪些行动前提**，什么时候可以执行，什么时候应该停止或放弃。
- **核心方法：** 提取候选动作依赖的记忆，估计出错风险和核验代价，用**信息价值（VOI=核验前损失-核验后预期损失-核验成本）**选检查；已有**逐步更新、贪心选择和两步补充前瞻**。
- **创新空间：** **这是对原方案核心思想覆盖最直接的一篇**，它的主要问题是针对给定候选动作决定是否安全执行，实验侧重软件智能体

### [Enter the Mind Palace: Reasoning and Planning for Long-term Active Embodied Question Answering](https://proceedings.mlr.press/v305/ginting25a.html)（2025）

- **研究问题：** 机器人怎样结合**过去的记忆和当前的探索**，回答跨时间的具身问题。
- **核心方法：**构建结构化长期记忆，根据问题检索历史信息或导航观察，并用**信息价值**判断是否继续收集证据。
- **创新空间：**它已经覆盖“**查旧记忆＋去现场＋何时停止**”。我的方案若继续做，需要突出**记忆疑点对不同核验操作作用的影响**，并提出可验证的联合决策机制

### [ESearch-R1: Learning Cost-Aware MLLM Agents for Interactive Embodied Search via Reinforcement Learning](https://arxiv.org/abs/2512.18571)（2025）

- **研究问题：** 指令含糊、目标不明确时，机器人怎样避免反复询问或盲目实地搜索。
- **核心方法：** 将**询问用户、检索记忆、物理导航**统一为行动选择，通过成本感知强化学习学习低成本决策策略。
- **创新空间：** 它已经研究了**不同动作的代价权衡**。我的方案更关注**已经保存的记忆可能出错或过期**，以及核验结果如何改变导航；但不能再把“统一比较检索和移动成本”作为新贡献。

### [EvoMemNav: Efficient Self-Evolving Fine-Grained Memory for Zero-Shot Embodied Navigation](https://arxiv.org/abs/2606.03509)（2026）

- **研究问题：** 怎样保留细粒度视觉记忆、区分相似目标，避免机器人导航时认错目标或过早停止。
- **核心方法：** 建立保留原始视图的**房间—视图—物体记忆图**，先筛选候选区域，再调用 VLM 核验，并在任务后更新记忆。
- **创新空间：** 它已覆盖**历史视觉证据、预算内筛选、目标确认和记忆更新**。我的方案如要有区别，重点应是**不同核验操作之间如何联合选择及影响后续路线**

### [Lifelong Small-Object Navigation in Changing Object Layouts: A Benchmark and Method](https://arxiv.org/abs/2610.10125)（2026；IVAM-Nav）

- **研究问题：** 小物体经常被遮挡或搬动，机器人怎样重复寻找它们，并及时发现历史位置已经失效。
- **核心方法：** 用**多视角观察、视点关联记忆**保存物体线索；回访旧观察点，对比新旧画面，发现变化后更新记录。
- **创新空间：** 它已直接涉及**过期记忆、现场核验、视点选择和更新**。我的方案需要证明：在位置过期以外的多种疑点下，**旧图复核、计算修正与现场复查怎样统一决策**，能比已有回访策略带来实质收益。

### [Searching in Space and Time: Unified Memory-Action Loops for Open-World Object Retrieval](https://arxiv.org/abs/2511.14004)（2025；STAR）

- **研究问题：** 目标可能用过去的状态描述、现在却已移动；机器人怎样结合**时间上的回忆**与**空间中的搜索**找到目标。
- **核心方法：** 基于长期记忆和工作记忆，让视觉语言模型逐步选择**查询历史**或**导航／交互**，根据反馈继续行动。
- **创新空间：** 它与我的**应用场景和闭环流程高度接近**。因此不能声称首次提出“先查历史再去现场”或“边执行边调整”；要证明的是**针对不可靠记忆的核验选择规则及预算内求解算法**优于一般的记忆—行动循环。



## 三、GPT对比后的判断

| 判断 | 结论 |
| --- | --- |
| **与 AMV 的重合** | **高。**“记忆不可靠时，按照行动风险与核验成本决定检查什么、是否继续检查”已被直接研究。 |
| **与 STAR、Mind Palace 的重合** | **较高。**“查询过去的记忆”和“去现场获得新证据”的结合及动态调整，也已有研究。 |
| **与 ESearch-R1、IVAM-Nav、EvoMemNav 的重合** | **部分重合。** 分别覆盖成本感知决策、过期记忆现场复核、细粒度视觉确认与更新。 |
| **仍有可能研究的部分** | **异构核验与机器人导航成本的具体联合求解机制**，但必须提出清晰算法，并与信息和预算一致的强基线比较。 |
| **当前最大风险** | 原方案已经有较完整的**问题描述与技术流程**，却还没有足以区别于 AMV、STAR 等研究的**明确算法贡献**。 |

现在应思考：在这些已有工作的基础上，原方案是否仍值得从“核验与导航联合决策算法”深入？如果值得，最需要收窄和突破的算法问题是什么；如果不值得，是否应调整选题？
