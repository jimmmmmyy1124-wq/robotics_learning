# Ubuntu 终端基础命令速查


## 1. 常用路径符号

| 符号 | 含义 |
|---|---|
| `~` | 用户主目录，例如 `/home/jimmy` |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `/` | 系统根目录 |

---

## 2. 目录操作

```bash
pwd                 # 查看当前所在位置
ls                  # 查看当前目录内容
ls -la              # 查看详细内容和隐藏文件
tree -L 2           # 以树状显示两层目录

cd 目录路径          # 进入指定目录
cd ..               # 返回上一级目录
cd ~                # 返回主目录

mkdir 目录名         # 创建一个目录
mkdir -p 路径        # 创建多层目录
rmdir 目录名         # 删除空目录
```



---

## 3. 文件操作

```bash
touch 文件名               # 创建空文件
nano 文件名                # 创建或编辑文件
cat 文件名                 # 显示文件内容

cp 原文件 新文件            # 复制文件
cp -r 原目录 新目录         # 复制整个目录

mv 旧名称 新名称            # 移动或重命名
rm 文件名                  # 删除文件
rm -r 目录名               # 删除目录及其内容
```

`nano` 常用快捷键：

| 操作 | 快捷键 |
|---|---|
| 保存 | `Ctrl + O` |
| 确认文件名 | `Enter` |
| 退出 | `Ctrl + X` |

> `rm -r` 删除后通常无法恢复，执行前应先确认路径。

---



## 4. 终端常用操作

| 操作 | 快捷键或命令 |
|---|---|
| 终止当前程序 | `Ctrl + C` |
| 清空画面 | `clear` 或 `Ctrl + L` |
| 查看历史命令 | `history` |
| 调出上一条命令 | `↑` |
| 搜索历史命令 | `Ctrl + R` |
| 自动补全 | `Tab` |

当终端显示 `>` 时，通常表示命令还没有输入完整，可以按 `Ctrl + C` 取消。

---

## 5. 软件安装与管理员权限

```bash
sudo apt update                 # 更新软件源
sudo apt install 软件包名       # 安装软件
sudo apt install -y 软件包名    # 自动确认安装
sudo apt remove 软件包名        # 卸载软件
```



输入 `sudo` 密码时，终端不显示字符是正常现象。

## 6. source

把这个文件中的环境设置加载到当前终端。

```bash
source 文件路径
```
