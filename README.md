# Robotics Learning Log

本仓库用于记录机器人、ROS 2、Python及相关算法的实验过程、代码和阶段成果。

## 当前学习目标

1. 掌握 ROS 2 基础；
2. 掌握 Python 基础；
3. 学习机器人规划与感知算法；
4. 养成规范的科研实验记录习惯。

## 文件夹说明

- `experiment_logs`：实验过程、问题与结果记录；
- `weekly_reports`：每周学习和实验总结；
- `code`：练习代码和项目代码；
- `images`：实验截图和结果图片。

## 笔记方式

理论知识主要使用纸质笔记记录，本仓库重点保存实验记录、代码和可复现结果。
